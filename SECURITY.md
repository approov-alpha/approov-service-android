# Security Policy

## Supported Versions

We supply updates and patches in the latest release. Earlier versions will still work, but will have fewer features than later versions.
We recommend that all users of this package update to the latest version.

| Version | Supported          |
| ------- | ------------------ |
| 3.7.x   | :white_check_mark: |
| < 3.7   | :x:                |

The first release of the Approov Package for Android is 3.7.0. The per-stack packages it replaces ([OkHttp](https://github.com/approov/approov-service-okhttp), [HttpsURLConnection](https://github.com/approov/approov-service-httpsurlconn), [Volley](https://github.com/approov/approov-service-volley) and [gRPC](https://github.com/approov/approov-service-android-java-grpc)) keep their own security policies.

## Reporting a Vulnerability

Thank you for telling us about possible security vulnerabilities in this project.
Please do not publish details in a public issue or PR. Send a private email to support@approov.io. Please tell us which version your report refers to.

We will reply to your message promptly.
